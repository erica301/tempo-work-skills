# TEMPO Work skills

The 17 Claude skills from TEMPO Work, the self-paced course by Erica Layer (Layer Advisory). They install together as one plugin, called `tempo-work`.

Each skill teaches Claude to do one job the way I do it. A skill only switches on when a task matches it, so the ones you don't need stay out of the way.

## Before you install: check it

Anything someone else made can be a security risk, including this. Start a new chat in Claude and paste:

```
Before I install it, audit the Claude plugin at https://github.com/erica301/tempo-work-skills. Read every file. Tell me who made it, what it can reach, what it can do with that, whether it sends anything anywhere or takes instructions from anywhere else, and whether it asks for passwords or keys. Then give me one verdict: safe to install, install with limits, or don't install.
```

Go on if the verdict is safe to install, or install with limits. If it gives limits, follow them. It may say you already have some of these skills: that's fine, you can remove your old copies afterwards.

## Install

You need a paid Claude plan (Pro, Max, Team or Enterprise).

1. In Claude, open **Customize**, then **Plugins**.
2. Click **Add**, then **Add marketplace**, paste `erica301/tempo-work-skills`, and confirm.
3. Open **Tempo work** (from tempo-work-skills) and click **Add**. This second Add is the one that puts the skills in your Claude.
4. **Updates:** when I announce a new version, open **Customize**, then **Plugins**, then **Manage marketplaces**. Click the **⋯** beside tempo-work-skills and choose **Check for updates**. (Sync automatically only works if you connect Claude to your own GitHub account, so most people use Check for updates.)
5. Start a new chat and ask: "Which tempo-work skills can you see?" It should list all 17.

Some skills run on their own when a task matches, like checking a sum with a script. To make sure they do, also paste the instruction lines from the course portal's skill library into Settings, Account, Instructions for Claude. You only do this once.

## What's inside

**Keep you safe:** check-before-install, security-check

**Check its work:** extraction-map, ready-to-send, numbers-by-script, report-review, meeting-actions, adversarial-review

**Make it yours:** voice-interview, design-interview, context-interview. Each interview makes your own skill (my-voice, a design system, my-context). What it makes is yours, so plugin updates never change it.

**Think it through:** widen-it, board-interview (makes your own my-board)

**Build your own:** make-a-skill, make-an-automation, make-a-rubric, wrap-session

TEMPO Work learners: the course portal explains why each one matters and which lesson uses it.
