# My design

Your job is to make anything visual look like it came from me: my colours, my fonts, my logo used the right way, and my tone. Everything you need is in **My design profile** at the bottom of this skill. Read it before you make anything.

## If the profile is empty

If the profile below still says "Not filled in yet", don't invent a brand. Say so in one line and offer to set it up (about ten minutes). If I say yes:

1. **Ask for my brand guide** if I have one (a PDF, a page, a document). Read it in full and pull out the values. If I don't have one, ask for my website or two things I've made that look right.
2. **Ask only what's still missing, together, in one message,** and say "You can answer by number":
   1. Your main colours, as hex codes if you have them (for example #2B4C7E).
   2. Your fonts, for headings and for body text.
   3. Your logo: where it lives, and any rules (minimum size, never on a dark background).
   4. Three words for how your work should feel.
   5. Anything you never want to see: colours, styles, clip art, stock photos.
3. **Write the profile** in the shape below. Only values I gave you or that are in the guide. If a value is missing, write "not set" rather than picking one.
4. **Show it to me,** with a small sample (a heading, a paragraph, a button, a chart colour row) using the values, and ask "Anything to change?"
5. **Save it.** Give me a **Your turn:** to save the new version: ask you in a new chat to update the my-design skill with the filled-in profile, then press **Update** on the card that comes up, and check the description line didn't change.

## Every piece

1. Read the profile. Use its colours, fonts and rules exactly.
2. **Check before you show me:** colours only from the palette, the accent colour used sparingly, text readable against its background, the logo used by its rules, nothing from the "Never" list.
3. If the profile doesn't cover something (a chart needs more colours than the palette has), say what you chose and why.

## Where this works, and where it doesn't

This skill styles what you make in a chat: pages, artifacts, one-pagers, charts. Slide decks and documents made from claude.ai's own templates read a **design system** instead. If I ask for one of those, tell me in one line, and offer to help me set up a design system from this profile.

## Rules

- Don't publish, share or send anything you make.
- Never use a logo or image you can't see. If you need my logo, ask me for it.
- If I change something ("make the headings darker"), ask once whether to add it to the profile, and propose the exact line.
